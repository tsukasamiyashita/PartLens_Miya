# PartLens_Miya-v1.0.0 取扱説明書

PartLens_Miya-v1.0.0 は、PDFファイルやCADデータ（DXFファイルなど）の2D図面から、部品の情報を自動で読み取って整理し、きれいなExcel形式の部品表（BOM）を作成できるWindows向けデスクトップアプリです。
図面を見ながら手作業でExcelに転記する手間や入力ミスを減らし、どなたでも簡単に部品表を作成・集計することができます。

---

## 1. アプリの概要と主な機能

- PDF図面およびCAD図面（DXF形式）の読み込みと画面プレビュー表示
- 図面内の部品欄・表題欄・ブロック属性・テキストからの部品データ自動抽出
- 図面プレビュー上でマウスを使って好きな場所（部品表の範囲など）を四角く囲み、その範囲内の文字や表だけを狙って読み取る「範囲選択抽出」機能
- JIS規格の材質記号（SUS304、SS400、S45C、A5052など）や表面処理、数量、寸法の自動判別
- 部品表の画面上での直接編集（行の追加・削除・並び替え・検索・元に戻す機能）
- 複数枚の図面から読み取った部品データの統合と、同じ部品の自動名寄せ（数量の合算）機能
- 寸法（板材・丸棒・パイプなど）と材質の比重から、部品1個あたりの重さ（単重）を自動計算する重量計算ツール
- 用途に合わせて選べるExcelファイル（.xlsx形式）およびCSVファイルへの出力機能（合計数量・総重量・合計金額の計算式や図面プレビュー画像付き出力にも対応）
- すぐにお試しいただける「サンプル図面（PDF・DXF）の自動作成・読み込み」機能

---

## 2. 動作環境

- 対応OS: Windows 11（64ビット版推奨） / Windows 10
- 画面解像度: 1280 x 800 以上（1920 x 1080 フルHD以上を推奨）
- その他: 本アプリは単体で動作するため、特別なソフトやプログラム環境を事前にインストールする必要はありません。ExcelがインストールされていないパソコンでもExcelファイル（.xlsx）を作成・保存できます。

## 3. インストールと起動方法（初回起動時のご注意）

### 起動の手順
1. 配布されたフォルダ（またはZIPファイルを展開したフォルダ）の中にある `PartLens_Miya-v1.0.0.exe` を探します。
2. `PartLens_Miya-v1.0.0.exe` をダブルクリックするとアプリが起動します（面倒なインストール作業は不要です）。

### 初回実行時にWindowsの青い警告画面が表示された場合（重要）
パソコンに初めてダウンロードした `.exe` ファイルを開く際、Windowsのセキュリティ機能（Windows Defender SmartScreen）によって「WindowsによってPCが保護されました」という青い画面が表示されることがあります。
これは個人や社内で作成されたアプリに対して自動的に表示される確認画面ですので、以下の手順で安全に起動できます。

1. 青い画面の中央付近にある「詳細情報」という文字（下線が引かれたリンク）をクリックします。
2. 画面の下部に「実行」というボタンが新しく表示されます。
3. 「実行」ボタンをクリックすると、アプリが正常に起動します（2回目以降はこの画面は表示されなくなります）。

## 4. 基本的な使い方

### ステップ1：図面ファイルを読み込む
1. 画面上部の「図面ファイルを開く (PDF/DXF)」ボタンをクリックします。
2. パソコン内のPDF図面（`.pdf`）またはCAD図面（`.dxf`）を選択して開きます（複数ファイルを同時に選ぶこともできます）。
3. 「フォルダ一括読込」ボタンを押すと、指定したフォルダの中にある図面ファイルをまとめて読み込むことができます。
4. お手元に図面ファイルがない場合は、「サンプル図面で試す」ボタンをクリックすると、動作確認用のサンプルPDF図面とDXF図面が自動で作られて画面に読み込まれます。

### ステップ2：図面から部品情報を抽出する
- ファイルを読み込むと、自動的に図面内の表や文字が解析され、画面右側の部品表リストに部品データが並びます。
- もし図面内の特定の場所（右上や右下の部品欄など）だけを読み取りたい場合は、画面左側のプレビュー上部にある「範囲選択して部品抽出」ボタンをオンにし、図面の上でマウスを左ドラッグして四角く囲んでください。囲んだ範囲の中にある文字だけを読み取って部品表に追加できます。
- 部品表の行をクリックすると、図面のどの位置から読み取られた部品かがプレビュー画面上でハイライト表示されます。

### ステップ3：部品表を確認・編集する
- 表の中の項目（品番、品名、型式・寸法、材質、表面処理、数量、単重、単価など）をダブルクリックすると、その場で直接文字や数値を書き換えることができます。
- 画面右下の「選択行の詳細編集」エリアを使って、材質や表面処理を一覧から選んで入力することも可能です。
- ツールバーの「重複部品の名寄せ統合」ボタンを押すと、同じ図番・品名・材質の部品が1行にまとめられ、数量が自動で合算されます。
- 「寸法から重量自動計算」や「重量計算機」ボタンを押すと、部品の寸法（例：`t10x100x200` や `φ30x150`）と材質から重さ（kg）を自動計算して入力できます。

### ステップ4：Excelファイルに出力する
1. 画面上部の「案件名 / 製品名」や「総合図番」「作成者」などの項目を必要に応じて入力します。
2. 画面右下の「Excel部品表を出力 (.xlsx)」ボタンをクリックします。
3. 保存先とファイル名を指定して「保存」をクリックすると、きれいに整えられたExcelファイルが出力されます。
4. 出力形式を細かく選びたい場合（標準フォーマット、購買・見積用、加工用、図面別シート分割、図面プレビュー画像の添付など）は、「Excel出力設定」ボタンから設定を変更できます。

## 5. 困ったときは

- 文字がうまく読み取れない場合：
  スキャンされた古い紙図面（文字データが含まれない画像だけのPDF）の場合、自動抽出では文字が検出されないことがあります。その場合は、左側に図面を表示した状態で、右側の「＋ 行追加」ボタンや詳細編集フォームを使って図面を見ながら快適に入力することができます。
- 操作を間違えてしまった場合：
  ツールバーの「元に戻す (Undo)」ボタンをクリックすると、直前の状態に戻すことができます。
- 作業を途中で保存したい場合：
  画面上部の「プロジェクト保存」ボタンから現在の作業状態をファイルに保存し、後日「プロジェクト読込」ボタンから続きを再開することができます。
