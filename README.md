# PartLens_Miya-v1.0.0 取扱説明書

PartLens_Miya-v1.0.0 は、PDFファイル・CADデータ（DXF形式）・スキャン画像などの2D図面から部品の情報を自動で読み取り、そのまま業務で使えるExcel形式の部品表（BOM）を作成できるWindows向けデスクトップアプリです。

通常の自動読み取り機能（インターネット接続不要）に加え、Googleの最新AI（Gemini API）を使った高精度な図面画像・文字ハイブリッド解析機能を搭載しており、複雑な組立図やスキャンされた紙図面からでも素早く正確に部品表を作成できます。

---

## 1. アプリの概要と主な機能

- 多様な2D図面の読み込みとプレビュー表示
  - PDF図面（`.pdf`）、CAD図面（`.dxf`）、および画像図面（`.png` / `.jpg` / `.bmp` / `.tif` / `.webp`）に対応しています。
  - マウスホイールでの拡大・縮小、ドラッグでの移動、ページ切り替えが可能です。
- 最新Gemini AIによる高精度な部品表・表題欄・寸法読み取り機能
  - 図面の画像と内部の文字データを同時にAIへ送り、部品欄・表題欄・バルーン注記を漏れなく読み取ります。
  - 最新のGeminiモデル一覧から用途に合わせてモデルを選択でき、ボタン1つでの最適モデル自動選択や、APIからの最新モデル一覧取得にも対応しています。
- インターネットやAPIキーがなくても使えるローカル自動抽出機能
  - PDFやDXFに含まれる表や文字データ、表題欄、単品図の材料寸法から、オフライン環境でも自動で部品情報を抽出します。
- 狙った場所だけを読み取る「範囲選択抽出」機能
  - 図面プレビュー上で部品欄や注記のエリアをマウスで四角く囲むだけで、その範囲だけをピンポイントでAI解析または文字抽出できます。
- 部品表の簡単編集・重量計算・AIデータ補正機能
  - 表のセルをダブルクリックして直接書き換えたり、行の追加・複製・削除・並び替え・キーワード検索・元に戻す（Undo）操作が行えます。
  - 板材・丸棒・丸パイプ・角パイプ・六角棒などの寸法と材質（JIS規格）から、部品1個あたりの重さ（単重 kg）を自動計算します。
  - 「AIデータ補正・補完」機能により、材質記号の表記ゆれ統一や、市販品型番からのメーカー名・調達区分の自動補完が可能です。
- 実務に合わせたExcelファイル（.xlsx）・CSV出力・クリップボードコピー
  - 「標準部品表」「購買・見積手配用（購入品集計シート付き）」「製造・加工手配用（加工品製作シート付き）」の3種類のフォーマットから選んでExcel出力できます。
  - 総重量や合計金額の自動計算式（SUM関数）、図面別シート分割、2D図面プレビュー画像シートの添付にも対応しています。
  - 「Excel貼付コピー」ボタン（または `Ctrl + C`）で、現在開いている別のExcelシートへそのまま貼り付けることもできます。
- すぐにお試しできる「サンプル図面」自動作成機能
  - お手元に図面ファイルがなくても、「サンプル図面で試す」ボタン1つでサンプルのPDF組立図とDXF図面を作成してすべての機能を体験できます。

## 2. 動作環境

- 対応OS：Windows 11（64ビット版推奨） / Windows 10
- 画面解像度：1280 x 800 以上（1920 x 1080 フルHD以上を推奨）
- 画面カラー：見やすさを重視したライトモード（明るい画面表示）固定で動作します。
- インターネット接続：Gemini AI解析機能を使う場合のみ必要です（通常のローカル解析やExcel出力はオフラインでもご利用いただけます）。
- 事前準備：本アプリは単体で動作するため、特別なソフトやプログラム環境をインストールする必要はありません。パソコンにExcelが入っていなくてもExcelファイル（`.xlsx`）を作成・保存できます。

## 3. インストールと起動方法（初回起動時のご注意）

### アプリの起動手順
1. 配布されたフォルダ（またはZIPファイルを右クリックして「すべて展開」したフォルダ）を開きます。
2. フォルダの中にある `PartLens_Miya-v1.0.0.exe` をダブルクリックすると、すぐにアプリが起動します（インストール作業は不要です）。

### 初回実行時にWindowsの青い警告画面が表示された場合（重要）
パソコンに初めてダウンロードした `.exe` ファイルを開く際、Windowsのセキュリティ機能（Windows Defender SmartScreen）によって「WindowsによってPCが保護されました」という青い確認画面が表示されることがあります。
これは新規に作成されたアプリに対して自動的に表示される画面ですので、以下の手順で安全に起動してください。

1. 青い画面の文章の下にある `詳細情報` という文字（下線が引かれたリンク）をクリックします。
2. 画面の右下に `実行` というボタンが新しく表示されます。
3. `実行` ボタンをクリックすると、アプリが正常に起動します（2回目以降はこの確認画面は表示されなくなります）。

## 4. 基本的な使い方（5つのステップ）

### ステップ1：Gemini AIの設定とモデル選択（AI高精度解析を使う場合）
1. 画面上部の `Gemini AI設定` ボタン（または左側プレビュー上部の `一覧/設定` ボタン）をクリックします。
2. お持ちの Gemini APIキーを入力欄に貼り付けます。
3. モデル一覧表から使用するAIモデルを選択します（初期状態では図面解析に最適な `gemini-3.8-flash` が選ばれています）。
   - 用途に迷ったときは、一覧の上にある自動選択ボタンをクリックするだけで最適なモデルを選べます：
     - `★最適モデル(バランス)`：精度・速度・コストのバランスが最も良い標準推奨モデル（`gemini-3.8-flash`）を選びます。
     - `精度優先`：複雑な組立図や読みにくいスキャン図面向けに高精度モデル（`gemini-4-carbon` / `gemini-4-argon` / `gemini-4-hydrogen`）を選びます。
     - `高速・省コスト`：大量の図面を素早く処理したい場合に高速軽量モデル（`gemini-3.5-flash-lite`）を選びます。
   - `APIから最新モデル一覧を取得` ボタンを押すと、お使いのAPIキーで利用可能な最新のGeminiモデル一覧をインターネット経由で取得して一覧表を更新できます。
4. `接続テスト` ボタンを押すと、APIキーと選択モデルで正しく通信できるかその場で確認できます。
5. `設定を保存` をクリックすると設定が保存され、次回起動時も自動で引き継がれます。
   - メイン画面左側の `Geminiモデル` ドロップダウンや `★最適選択` ボタンからも、いつでもワンクリックでモデルを切り替えられます。

### ステップ2：2D図面ファイルを読み込む
1. 画面上部の `図面ファイルを開く (PDF/DXF)` ボタンをクリックします。
2. パソコン内の図面ファイル（`.pdf` / `.dxf` / `.png` / `.jpg` など）を選択して開きます（複数ファイルを同時に選択できます）。
3. フォルダ内の図面をまとめて読み込みたい場合は、`フォルダ一括読込` ボタンをクリックしてフォルダを選択します。
4. まずは動作を試してみたい場合は、`サンプル図面で試す` ボタンをクリックしてください。サンプル用のPDF組立図とDXF図面が自動生成され、部品表が読み込まれます。

### ステップ3：図面から部品表を読み取る（AI解析・範囲選択抽出）
- 図面全体を高精度に読み取る場合：
  - 画面左上の `AI図面解析 (Gemini)` ボタンをクリックすると、AIが図面画像と文字情報を組み合わせて解析し、部品表を作成します。
  - 複数の図面を読み込んでいる場合は、`全図面をAI一括解析` ボタンで全ページをまとめて解析できます。
- 図面の中の特定の場所（部品欄など）だけを読み取る場合：
  - プレビュー上の `範囲選択して部品抽出` ボタンをクリックして `ON` にします。
  - 図面上の読み取りたい部品表や注記エリアを、マウス左ドラッグで四角く囲んで離します。
  - Gemini APIキーが設定されていれば囲んだ範囲の画像を高解像度AI解析し、未設定の場合は範囲内の文字データから部品を抽出して一覧に追加します。

### ステップ4：部品表を確認・編集・補正する
- セルの直接編集：
  - 表のセル（図番、品名、型式・寸法、材質、表面処理、数量、単重、単価など）をダブルクリックすると、その場で直接書き換えられます。
  - 部品行をクリックすると、図面プレビュー上でその部品が記載されている位置がオレンジ色の枠でハイライト表示され、下部の詳細フォームからも編集できます。
- 重量の自動計算：
  - `寸法から重量計算` ボタンを押すと、型式・寸法欄（例：`t10x100x200`、`φ30x150`、`φ40xt3x300`、`50x50xt3.2x400`、`HEX24x100`）と材質から単重（kg）を一括計算します。
  - `重量計算機` ボタンを押すと、形状と寸法数値を入力して単重を計算し、選択行へ反映できます。
- 重複部品の統合とAIデータ補正：
  - `重複名寄せ統合` ボタンを押すと、同じ図番・品名・寸法・材質の部品が1行にまとめられ、数量が自動で合算されます。
  - `AIデータ補正・補完` ボタンを押すと、AIが材質のJIS規格表記への統一や、市販品型番からのメーカー名・調達区分・単重の補完を自動で行います。

### ステップ5：Excelファイルに出力する
1. 画面右上の「案件名/製品名」「総合図番」「作成者」を必要に応じて入力します。
2. 画面右下の緑色のボタン `Excel部品表を出力 (.xlsx)` をクリックします。
3. 保存先とファイル名を指定して「保存」をクリックすると、罫線・色分け・合計計算式（数量・総重量・金額）が整えられたExcelファイルが出力されます。
4. 出力スタイルを変更したい場合は、`Excel出力設定...` ボタンから以下を選択できます：
   - 標準部品表フォーマット（全項目）
   - 購買・見積手配用フォーマット（総合部品表に加え、購入品・標準部品のみを集計した専用手配シートを自動作成）
   - 製造・加工手配用フォーマット（総合部品表に加え、加工品・板金・製缶品のみを集めた製作手配シートを自動作成）
   - 図面別シートの同時作成、重複部品の名寄せ集計、2D図面プレビュー画像シートの添付のON/OFF

## 5. 便利な機能とショートカットキー

- 表の並び替え（ソート）：部品表の列見出し（No.、図番、品名、数量、総重量など）をクリックすると、昇順（▲）・降順（▼）で並び替えができます。
- 右クリックメニュー：部品表の行や図面プレビュー画面を右クリックすると、よく使う操作メニューがその場で開きます。
- 他のExcelへの直接コピー＆ペースト：部品表の行を選んで `Excel貼付コピー` ボタン（またはキーボードの `Ctrl + C`）を押すと、開いている別のExcel画面にそのまま `Ctrl + V` で表データを貼り付けられます。
- 主なキーボードショートカット：
  - `Ctrl + O`：図面ファイルを開く
  - `Ctrl + S`：Excel部品表を出力する
  - `Ctrl + Z`：直前の操作を元に戻す（Undo）
  - `Ctrl + Y`：元に戻した操作をやり直す（Redo）
  - `Ctrl + C`：選択中の部品行をExcel貼り付け形式でコピーする
  - `Delete`：選択中の部品行を削除する
  - `F1`：この使い方ガイド（取扱説明書）を開く

## 6. 困ったときは（よくあるご質問）

- Q. スキャンされた紙図面（文字データが入っていないPDFや画像）から部品表を作れますか？
  - A. はい、作れます。上部の `Gemini AI設定` でAPIキーを設定してから `AI図面解析 (Gemini)` を実行してください。AIの画像認識機能によって、スキャン図面や写真・画像ファイルからでも文字や部品表を読み取ることができます。
- Q. どのGeminiモデルを選べばよいか分かりません。
  - A. 通常は初期設定の `gemini-3.8-flash`（`★最適モデル(バランス)`）のままで問題ありません。文字が小さくて読みづらい図面や複雑な組立図では `精度優先`（`gemini-4-hydrogen` や `gemini-4-argon` など）、枚数が非常に多い図面を素早く処理したいときは `高速・省コスト`（`gemini-3.5-flash-lite`）をお試しください。
- Q. Excel出力時に「ファイルが他のソフトで開かれています」と表示されました。
  - A. 同じ名前のExcelファイルをすでにExcelで開いている場合、上書き保存がブロックされます。開いているExcelファイルを閉じてから、もう一度出力ボタンを押してください。
- Q. 作業を途中で保存して、明日続きから編集することはできますか？
  - A. はい、画面上部の `プロジェクト保存` ボタンから作業ファイル（`.plens.json`）を保存しておけば、次回 `プロジェクト読込` ボタンから図面と部品表の状態をそのまま復元して再開できます。
